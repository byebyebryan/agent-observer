canonical LF encoding, strict parse and full-feed consumer filtering per measured
generation: 24 measured reads per trial. Each version/size runs ABBA a7-full /
candidate-working / candidate-working / a7-full, then one current full-feed lane
to show explicit full-history access remains available. GC stays disabled.
Generation and read CPU are also reported separately. Hashing, semantic equality
and byte accounting are outside measured CPU windows; the measured frame encode
already includes those bytes. Parser/frame warmup is excluded equally.
