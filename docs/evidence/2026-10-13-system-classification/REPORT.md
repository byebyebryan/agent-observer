# System classification acceptance, 2026-10-13

Observer **0.7.0a1 / API 4 / snapshot-watch 6 / Service 4** with
Mesh **0.1.0a17 / Agent profile v3 / SDK 1** is accepted and selected for
collection, read CLI and Agent publication on Snap and Starship.
[Bounded evidence](acceptance.json) binds the exact wheel hashes, source freezes,
native cases, conformance, cached delivery and paired adoption gates.
These local branch checkpoints and installed packages are not a hosted release.

## Behavior and compatibility

Supported native `threadSource=system` survives observation as `kind=system`.
This client helper classification is independent of persistence, runtime, phase
and activity. Confirmed children retain established precedence; unsupported
tags stay unknown with a finite metadata issue. Raw snapshots preserve system
identities. Ordinary human list/watch views hide them by default;
`--include-system` and exact identity selection retain diagnostic access.
Reconciliation precedes filtering, including positive reclassification of a
retained unknown row.

The new closed enum uses a new API/read/Service tuple and explicit Agent v3
profile. Old clients reject it; there is no automatic downgrade. Mesh Read 1,
Delivery 1, SDK 1, historical Agent v1/v2 schema bytes, Tmux v1/native a7 and the
independent historical writer remain unchanged. Reviewed Mesh lock revision 4
freezes the new profile alongside prior references.
