## Source and native authority

Snap has `claude-code 2.1.294-1`, Agent View enabled and five ordinary interactive
registrations. Three workers retain deleted executable images through a package
upgrade. Native PID domain, process birth, UID, executable locator and stable
UUID registration authenticate their source; no terminal/tmux/window evidence
is read and no provider release/hash allowlist selects support.

The [isolated passivity receipt](passivity.json) rejects
`claude agents --json --all`: even an empty private roster writes preferences,
a preferences backup and job pins. No ordinary roster command was invoked.
The adapter instead reads bounded provider-owned session and retained-job files.
Native filesystem events trigger refreshes; periodic reconciliation remains.

An authenticated current registration proves running. A stable current native
status proves working for busy/shell, waiting for interactive idle, and blocked
for typed permission/question waits. Generic dialogs and unproved readiness
remain unknown without erasing a proved runtime. Phase freshness comes from
the authenticated status read, never process liveness alone. Native status
clocks must be valid and no later than the observation sample.

Parked requires an exact terminal retained job, idle tempo, native terminal
clock, no pending work, complete stable metadata inventories, no bound worker
and positive saved existence. Saved-only omission or ordinary `/exit` cannot
prove parked. Background work without a registered worker remains unproved.
No background action/attachment route is accepted by this pass.

Runtime reads prove saved existence separately through bounded UUID-bound
transcript metadata. They do not run the SDK history catalog or renew conversation
activity. The independent history component uses its bounded SDK projection for
explicit titles, recorded cwd and conversation clocks. Classification uses
explicit UUID/role/sidechain envelopes independently of message timestamps.
The additional classification scan is bounded by 64 MiB per collection.
