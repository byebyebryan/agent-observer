## Client direction

Agent Plus is parked as an active desktop entry. Its source and retained
artifacts can remain historical/rollback inputs; no temporary launcher or new
frontend implementation is needed. Native Codex Command Center and Claude Agent
View remain user-managed workflows outside Observer. Claude's native use does
not restore its retired Observer adapter.

Immediate Observer utility is the read CLI and physical dashboards. Native
turn elapsed time includes blocking; time since turn completion is not the
entry time of a resumed idle runtime. Exact blocked/current-phase age remains
unavailable where the source does not expose it. An observed-series display
would require a separately accepted approximate-age policy, not a silent change
to RLCD's existing exact-state-age requirement.
